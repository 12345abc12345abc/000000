# IEG NEWS 프로젝트 규칙

- 언론 보도 목록은 **항상 메이저 언론사 순**(인지도 높은 매체 우선)으로 배열한다.
  기준 순서 예: 매일경제 → 전자신문 → 연합뉴스 → 아시아경제 → 폴리뉴스 → 파이낸스투데이 →
  데일리경제 → 내외경제TV → 공감신문 → ABC뉴스 → 피앤피뉴스.
  실제 전체 순서는 `IEG NEWS.dc.html`의 `RANK` 배열이 기준이며, 매체를 추가할 때는
  기존 매체의 상대 순서를 바꾸지 말고 사이에 끼워 넣는다. `RANK`에 없는 매체는 그룹 맨 뒤로 간다.
- 언론 보도는 연도 탭 안에서 월별 그룹(최신 월이 위)으로 나누고, 그룹 안에서 위 순서를 적용한다.
  연도 탭과 월 그룹은 `ARTICLES`에서 자동으로 만들어지므로 기사만 추가하면 된다.
  단, 월 그룹 부제는 `MONTH_SUB`에 직접 넣어야 한다.
- 발행 월이 확인되지 않은 기사는 `month`에 연도만 적는다(예: `'2018'`). 그 해 맨 뒤로 정렬된다.
- 기사 제목은 원문 전체 제목을 그대로 쓴다.
- 같은 기사의 포털·기관·자사 재게시본은 싣지 않고 원문만 싣는다.
- 개별 기사 URL이 없고 매체 홈/검색 페이지만 있는 건은 싣지 않는다.
- 브랜드 색: 대표 #FF0000, 보조 #FFB300, 무채색 #333333.
