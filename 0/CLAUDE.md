# IEG NEWS 프로젝트 규칙

- 언론 보도 목록은 **발행일 내림차순**(최신이 위)으로 배열한다.
  같은 날짜 안에서는 **메이저 언론사 순**(인지도 높은 매체 우선)을 적용한다.
  기준 순서 예: 매일경제 → 전자신문 → 연합뉴스 → 아시아경제 → 폴리뉴스 → 파이낸스투데이 →
  데일리경제 → 내외경제TV → 공감신문 → ABC뉴스 → 피앤피뉴스.
  실제 전체 순서는 `IEG NEWS.dc.html`의 `RANK` 배열이 기준이며, 매체를 추가할 때는
  기존 매체의 상대 순서를 바꾸지 말고 사이에 끼워 넣는다. `RANK`에 없는 매체는 맨 뒤로 간다.
- 기사 날짜는 `d`에 `'YYYY-MM-DD'`로 적는다. 기사 페이지의 `article:published_time` 등
  메타 태그에서 확인한 값을 쓴다.
- 소식지는 **호(월)마다 카드 하나**이고 그리드로 배열하며, **최신 호가 맨 앞**에 온다.
  미리보기는 호마다 크기가 같다(`aspect-ratio: 4/5`). 면이 2장 이상인 호는 커서를 올리면
  카드가 부챗살로 펼쳐지고(`.ieg-fan`), 1장짜리는 살짝 떠오른다(`.ieg-fan.is-single`).
  미리보기를 누르면 확대 보기가 열리고 거기서 좌우로 전체 면을 넘긴다.
- 부모 hover로 자식을 움직이는 효과는 인라인 스타일로 불가능하므로 `<helmet>`의 `<style>`에
  클래스로 정의한다. 색은 `:root`의 CSS 변수(`--red`, `--ink`, `--paper` 등)를 쓴다.
- 소식지는 `ISSUES` 배열에 `{ issue, pages: [{ src, cap }] }`로 넣는다.
  `issue`(예: `'2026. 09'`)는 그 호의 상단 배지에 그대로 나온다.
  새 호는 배열 맨 앞에 넣고, 이미지는 `0/uploads/`에 추가하되 기존 파일명은 건드리지 않는다
  (순서는 파일명이 아니라 배열이 정한다).
- 언론 보도는 연도 탭이나 월 그룹 없이 **한 줄씩 쭉 내려가는 목록**이며, 각 줄에 발행일을 표시한다.
- 목록은 `PER_PAGE`(현재 10)씩 끊어 1·2·3… 페이지 번호로 넘긴다.
  정렬과 페이지 수는 `ARTICLES`에서 자동 계산되므로 기사만 추가하면 된다.
- 발행일이 확인되지 않으면 `d`에 `'2024-05'`(일 미상) 또는 `'2017'`(월까지 미상)처럼 아는 만큼만 적는다.
  짧은 값은 내림차순에서 해당 기간 맨 뒤로 정렬된다.
- 기사 사진은 `img`에 원문 `og:image` 주소를 넣는다(핫링크). 넣지 않으면 썸네일 없이 표시된다.
  매체가 기사마다 같은 로고를 반환하면 넣지 않는다.
- 기사 제목은 원문 전체 제목을 그대로 쓴다.
- **같은 내용의 기사가 여러 매체에 실린 경우 메이저 언론사 것만 남기고 마이너 매체 것은 뺀다.**
  제목이나 취재 각도가 조금이라도 다르면 남긴다(별도 인터뷰·르포·기획, 다른 사실을 앞세운 제목 등).
  보도자료를 그대로 받아쓴 동일 제목 기사가 판단 기준이다.
  이 기준은 언론 보도 목록 상단에 안내 문구로 표시한다.
- 뉴스와이어(자사 보도자료 배포)는 싣지 않는다. 언론사 기사만 싣는다.
- 포털·기관·자사 재게시본은 싣지 않는다. 단 원문이 목록에 없어 그 재게시본이 해당 사안의
  유일한 기록이면 싣고 `note`에 출처를 적는다(예: `note:'뉴스와이어 재전송'`).
  재게시 매체는 `RANK` 맨 끝에 두어 원문 뒤에 오게 한다.
- 위 규칙에 걸리지 않는 기사는 빠짐없이 싣는다.
- 개별 기사 URL이 확인되지 않은 건은 싣지 않는다. 매체 홈/목록 페이지로는 연결하지 않는다.
- 브랜드 색: 대표 #FF0000, 보조 #FFB300, 무채색 #333333.
