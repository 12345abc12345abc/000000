# IEG NEWS 프로젝트 규칙

- 언론 보도 목록은 **발행일 내림차순**(최신이 위)으로 배열한다.
  같은 날짜 안에서는 **메이저 언론사 순**(인지도 높은 매체 우선)을 적용한다.
  기준 순서 예: 매일경제 → 전자신문 → 연합뉴스 → 아시아경제 → 폴리뉴스 → 파이낸스투데이 →
  데일리경제 → 내외경제TV → 공감신문 → ABC뉴스 → 피앤피뉴스.
  실제 전체 순서는 `IEG NEWS.dc.html`의 `RANK` 배열이 기준이며, 매체를 추가할 때는
  기존 매체의 상대 순서를 바꾸지 말고 사이에 끼워 넣는다. `RANK`에 없는 매체는 맨 뒤로 간다.
- 기사 날짜는 `d`에 `'YYYY-MM-DD'`로 적는다. 기사 페이지의 `article:published_time` 등
  메타 태그에서 확인한 값을 쓴다.
- 소식지는 **최신 호가 맨 위**이고, 지면마다 독립된 카드로 두되 **면 사이 간격을 일정하게** 해서
  아래로 쭉 내리며 고른 흐름으로 보게 한다. 호 배지와 지면은 같은 칼럼(820px)·같은 기준선을 쓴다.
  지면 한 장이 버튼 하나라, 누른 면이 그대로 확대 보기에 뜬다.
  확대 보기는 호 구분 없이 전체 면이 이어지고 끝에서 처음으로 순환한다.
- 지면에 요약·캡션·면 수 같은 텍스트를 붙이지 않는다. 호 배지(`2026. 09`)만 표시한다.
- 부모 hover로 자식을 움직이는 효과는 인라인 스타일로 불가능하므로 `<helmet>`의 `<style>`에
  클래스로 정의한다. 색은 `:root`의 CSS 변수(`--red`, `--ink`, `--paper` 등)를 쓴다.
- 소식지는 `ISSUES` 배열에 `{ issue, pages: [{ src }] }`로 넣는다.
  `issue`(예: `'2026. 09'`)는 그 호의 상단 배지에 그대로 나온다.
  새 호는 배열 맨 앞에 넣고, 이미지는 `0/uploads/`에 추가하되 기존 파일명은 건드리지 않는다
  (순서는 파일명이 아니라 배열이 정한다).
- 언론 보도는 연도 탭이나 월 그룹 없이 **한 줄씩 쭉 내려가는 목록**이며, 각 줄에 발행일을 표시한다.
- 목록은 `PER_PAGE`(현재 10)씩 끊어 1·2·3… 페이지 번호로 넘긴다.
  정렬과 페이지 수는 `ARTICLES`에서 자동 계산되므로 기사만 추가하면 된다.
- 발행일이 확인되지 않으면 `d`에 `'2024-05'`(일 미상) 또는 `'2017'`(월까지 미상)처럼 아는 만큼만 적는다.
  짧은 값은 내림차순에서 해당 기간 맨 뒤로 정렬된다.
- 기사 사진은 `img`에 원문 `og:image` 주소를 넣는다(핫링크). 매체가 기사마다 같은 로고를
  반환하면 넣지 않는다. 넣지 않은 기사는 같은 크기의 빗금 자리(`.ieg-thumb.is-empty`)가 대신 들어가
  모든 제목이 같은 줄에서 시작한다.
- 기사 제목은 원문 전체 제목을 그대로 쓴다.
- **같은 내용의 기사가 여러 매체에 실린 경우 메이저 언론사 것만 남기고 마이너 매체 것은 뺀다.**
  제목이나 취재 각도가 조금이라도 다르면 남긴다(별도 인터뷰·르포·기획, 다른 사실을 앞세운 제목 등).
  보도자료를 그대로 받아쓴 동일 제목 기사가 판단 기준이다.
  이 기준은 언론 보도 탭에서 탭 메뉴 우측에 안내 문구로 표시한다.
- 뉴스와이어(자사 보도자료 배포)는 싣지 않는다. 언론사 기사만 싣는다.
- 포털·기관·자사 재게시본은 싣지 않는다. 단 원문이 목록에 없어 그 재게시본이 해당 사안의
  유일한 기록이면 싣고 `note`에 출처를 적는다(예: `note:'뉴스와이어 재전송'`).
  재게시 매체는 `RANK` 맨 끝에 두어 원문 뒤에 오게 한다.
- 위 규칙에 걸리지 않는 기사는 빠짐없이 싣는다.
- 개별 기사 URL이 확인되지 않은 건은 싣지 않는다. 매체 홈/목록 페이지로는 연결하지 않는다.
- 브랜드 색: 대표 #FF0000, 보조 #FFB300, 무채색 #333333.

## 디자인 원칙

- 요청받지 않은 텍스트·라벨·숫자(부제, 일련번호, 수량, 요약 등)를 넣지 않는다.
- 글자를 키워서 강조하지 않는다. 제호는 최대 52px.
- 격은 **움직임·질감·마감**으로 올린다: 옅게 흐르는 배경색, 종이 입자, 세로 괘선,
  여백의 신문 망점과 커서를 따라오는 빛, 탭의 미끄러지는 검은 칸, 스크롤 시 떠오름.
- **화면이 처음 뜰 때는 아무것도 움직이지 않는다.** 등장 애니메이션을 넣지 않는다.
  (배경이 천천히 흐르는 것처럼 계속 이어지는 은은한 움직임과, 사용자가 일으키는 반응은 괜찮다.)
- 배경 장식(망점 등)은 **본문 칼럼 바깥 여백에만** 둔다. 글자 뒤로 비치면 읽기를 방해한다.
  배경 레이어는 본문 래퍼(`z-index:1`) 바깥의 `.ieg-bg` 안에 둔다.
- hover 강조는 선이 아니라 **항목 전체**에 준다 (떠오름 + 흰 배경 + 그림자 + 제목 빨강).
- 같은 역할의 요소는 같은 모양을 쓴다(`.ieg-btn`, `.ieg-tab`, `.ieg-chip`). 두 탭은 항상 같은 크기.
- 움직임은 은은하게 하고, `prefers-reduced-motion`이면 모두 끈다.
- hover의 `transform`과 등장 효과가 겹치지 않도록 등장 효과는 `translate` 속성만 쓴다.

## 화면 확인 방법

- 로컬에 Chrome이 있으므로 헤드리스로 실제 화면을 찍어 확인한다
  (`chrome --headless=new --screenshot --window-size=… --virtual-time-budget=20000 file:///…`).
- 헤드리스 Chrome은 창 폭을 최소 약 500px로 강제한다. 휴대폰 폭(390px)은 그 폭의 iframe 안에
  페이지를 띄워서 확인해야 한다. 그냥 창 폭을 줄이면 잘린 것처럼 보이지만 실제 버그가 아니다.
